# Getting started

Install the template pack and create projects. See the repo [README](../README.md).

## Documentation in generated solutions

Scaffolds include `build/Novolis.Documentation.props`, solution `README.md`, and per-project README placeholders for packable libraries. Follow [documentation-policy.md](https://github.com/Novolis-Platform/novolis-governance/blob/main/docs/documentation-policy.md) before publishing NuGet packages.
