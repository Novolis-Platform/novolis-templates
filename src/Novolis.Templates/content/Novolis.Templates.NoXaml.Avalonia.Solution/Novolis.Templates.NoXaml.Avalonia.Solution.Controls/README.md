# Controls

Reusable **code-only Avalonia controls** for the No-XAML solution.

Add custom `Control` subclasses here; reference from the App project. Keeps UI components separate from domain logic (`.Core`) and DTOs (`.Models`).

Packable as a NuGet library:

```bash
dotnet add package Your.PackageId
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (`net10.0`), Avalonia 12.
