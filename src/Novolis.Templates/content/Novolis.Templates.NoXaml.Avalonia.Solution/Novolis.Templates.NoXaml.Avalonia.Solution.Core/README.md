# Core

Domain and application services for the No-XAML Avalonia solution.

The sample includes `ITemperatureConverterService` / `TemperatureConverterService` — move business logic here and register interfaces in the App project's DI extensions.

Packable as a NuGet library:

```bash
dotnet add package Your.PackageId
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (`net10.0`).
