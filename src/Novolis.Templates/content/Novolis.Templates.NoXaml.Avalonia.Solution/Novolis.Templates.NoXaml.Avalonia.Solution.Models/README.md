# Models

Shared DTOs and view-model types for the No-XAML Avalonia solution.

Keep transport/view data here — no Avalonia UI references. Referenced by `.App`, `.Core`, and `.Controls` as needed.

Packable as a NuGet library:

```bash
dotnet add package Your.PackageId
```

**Prerequisites:** [.NET 10 SDK](https://dotnet.microsoft.com/download) (`net10.0`).
